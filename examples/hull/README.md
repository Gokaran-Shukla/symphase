# Example energy data (TOY)

The CSV files and `vasp_runs_NiAl/` were generated by `make_toy_data.py`.
**The energies are hand-made, physically plausible numbers for teaching — not DFT results.**
Structures in `structures/` are idealised prototypes (half-Heusler, full-Heusler, B2, L1₂, elements).

| file | system | entries |
|---|---|---|
| `NiAl_binary.csv` | Ni–Al | 14 |
| `TiNiSn_ternary.csv` | Ti–Ni–Sn | 23 |
| `TiZrNiSn_quaternary.csv` | Ti–Zr–Ni–Sn | 37 |
| `TiZrHfNiSn_5component.csv` | Ti–Zr–Hf–Ni–Sn | 51 |
| `NiAl_qha.csv` | Ni–Al with Debye–Grüneisen QHA and anharmonic columns (`--vib qha-debye`) | 14 |
| `NiAl_scph.csv` + `scph/` | Ni–Al with toy self-consistent phonon free energies (TDEP folders, SSCHA-style tables; `--vib scph`) | 14 |
| `vasp_runs_NiAl/` | Ni–Al as VASP folders (POSCAR + minimal OUTCAR) | 14 |

For real data: `symphase run Ti Ni Sn` (OQMD / Materials Project) or your own VASP runs.
